# 在线监测-在线监测页（六标签，Desktop First）页面设计

## 1) Meta Information
- Title: 在线监测
- Description: 以六标签导航查看设备概览、实时曲线、结果与调试信息（对接 127.0.0.1:8080）。
- OpenGraph:
  - og:title = 在线监测
  - og:description = 六标签在线监测：曲线/表格/日志

## 2) Global Styles（与截图一致的令牌建议）
- 字体：`system-ui, "Segoe UI", Arial`
- 字号：12px 为信息密度基准；卡片标题/主按钮 13~14px
- 页面背景：`#F3F6FB`（浅灰蓝底）
- 卡片背景：`#FFFFFF`
- 卡片描边：`#D9E2EF`
- 卡片阴影：`0 2px 10px rgba(15, 39, 71, 0.08)`（轻投影）
- 圆角：8px（卡片/标签/输入框），6px（徽标/小控件）
- 主色（Active Tab / 主按钮 / 曲线主线）：`#2B6DFF`
- 次强调（辅助线/状态点）：`#18A0FB`
- 文本主色：`#1F2A44`；次级文本：`#5B6B84`
- 表格表头：`#1F2A44`（白字）
- 行分隔线：`#E6EEF8`
- Hover：背景淡化 `rgba(43,109,255,0.08)`；边框加深一档
- 禁用态：opacity 0.45 + cursor not-allowed
- 数字等宽：`.mono { font-variant-numeric: tabular-nums; }`

## 3) Layout（布局系统与响应式）
- 桌面优先：整体采用 **CSS Grid（12 列）+ 卡片化** 的布局方式，匹配截图“卡片/表格/曲线并列”。
- 顶部为固定高度的“六标签栏”，内容区在其下方滚动。
- 推荐断点：
  - ≥ 1200px：曲线卡与表格卡并列（例如 9/3 或 8/4 列）。
  - < 1200px：卡片纵向堆叠（先曲线后表格），保证曲线可读性。

## 4) Page Structure（页面结构）
0. 顶部六标签栏（Tab Bar，固定在内容上方）
1. 内容区（根据标签切换的视图容器 View Container）
   - 概览：设备状态卡片/列表
   - 曲线：控制卡 + 信息卡 + 曲线卡 + 结果表卡 + 调试信息卡（或调试区）
   - 结果：全宽结果表卡
   - 事件：事件列表卡
   - 日志：调试信息/统计卡
   - 设置：本地显示参数表单卡

## 5) Sections & Components

### 5.0 顶部六标签栏（Tab Bar）
**布局**：固定在页面内容区顶部；容器 `display:flex`，标签等宽或接近等宽（与截图一致），整体为白底卡片感。
- 容器：白底、1px 描边 `#D9E2EF`、圆角 8px、内边距 6~8px
- 标签（Tab）
  - Inactive：背景 `transparent`，文字 `#1F2A44`
  - Active：背景 `#2B6DFF`，文字 `#FFFFFF`，轻微内阴影或加粗
  - Hover：背景 `rgba(43,109,255,0.08)`
- 标签文案：固定 6 个：**概览 / 曲线 / 结果 / 事件 / 日志 / 设置**
- 行为：切换标签不刷新页面、不重建 SSE 连接（保持对 8080 实时流的兼容与稳定性）。

### 5.1 曲线视图 - 顶部控制卡（Control Card）
**布局**：卡片内 `display:flex; gap:16px; align-items:center; flex-wrap:wrap;`；与截图一致的“控件密集但对齐”的观感。

**组件清单**（从左到右）：
1) 连接状态徽标（Status Badge）
- 默认：`未连接`
- 在线：`在线: GCxxxx` 或 `在线: GCxxxx（自动）`
- 断开：`连接断开: GCxxxx`
- 样式：padding 6x10、border 1px solid #ccc、圆角 6px

2) 设备选择（Select）
- Label：`设备`
- Option：默认显示 `等待 GC...`；仅纳入 `GC` 前缀设备
- 行为：
  - 你未手动选择时，可自动选中最近活跃设备
  - 切换设备后：清空该设备+当前通道缓存点并重绘

3) 通道选择（Select）
- Label：`Channel`
- 值域：0、1、2、3
- 切换通道后：切换到对应流并重绘

4) Y 轴范围（Number Input）
- `下限`：默认 0，宽度 64px
- `上限`：默认 40，宽度 64px
- 规则：上限必须大于下限；非法时提示并回退到最近一次合法值

5) 时间配置（Number Input）
- `采集时间(min)`：默认 2（用于“开始”后本地周期/窗口初始化的语义展示；不改变后端采集）
- `满屏时间(min)`：默认 2（决定曲线窗口滚动长度；需影响裁剪与 X 轴缩放）

6) 操作按钮
- `开始`：点击后先清屏（当前设备+通道）再下发 start
- `停止`：下发 stop
- `清屏`：仅本地清空并重绘，不请求后端
- 可用性：当设备状态 `canStart22=false` 时禁用开始/停止（后端未开启控制或设备未连接）

### 5.2 辅助信息条（Row 2）
**布局**：`display:flex; gap:18px; align-items:center; flex-wrap:wrap; font-size:12px; color:#333;`

1) 通道统计文本（`.mono`）
- 文案示例：`通道1: 0.000 min   0.000 pA`
- 数据：
  - min = 当前窗口累计时长（秒转分钟，保留 3 位小数）
  - pA = 最新 value（保留 3 位小数）

2) 峰高自适应（Checkbox）
- 默认勾选
- 行为：勾选时，Y 轴范围根据当前窗口 min/max 动态调整；取消勾选时，严格使用手动上下限

3) 谱图名称（Input）
- placeholder：`谱图名称`
- 默认仅做前端显示/标记（不强制写入后端）

### 5.3 调试状态行（Row 3）
- 位置：Row2 下方，间距 6px
- 字体：12px、#555、`.mono`
- 内容：
  - `设备: GCxxxx | lastCmd=... | 143=... | lastSeen=...s | last143=...s | control=on/off | elapsed=...min/...min`
- 目的：让你一眼判断“设备在线但没有 Cmd=143 数据流”等联调问题

### 5.4 实时曲线区域（Row 4 左侧）
**容器**：自适应宽度，建议最小宽度 800px（桌面优先），不足时允许缩小并触发右栏下移。

**绘制组件**：
- 优先建议 React 里封装 `RealtimeChart` 组件：
  - 可继续使用 Canvas（与现状一致，性能好）
  - 或替换为 ECharts/Visx（但需验证长时间运行与点数上限）

**交互与绘制规则（必须）**
- 数据来源：SSE `samples` 事件，仅显示“已选设备 + 已选 channel”
- 追加点规则：按 `t = (t0S - cycleStartS) + i*dtS` 拼出 x；y 为 values[i]
- 窗口裁剪：保留“满屏时间”内的点；额外保留少量缓冲点避免边缘断裂
- 清屏：清空该设备+通道的 pts 并重绘
- 断线：停止追加点；保留现有点

### 5.5 右侧结果表（Row 4 右侧）
**结构**：
- 头部条：深色背景（如 #444），白字，文案 `名称 | 含量(mg/m³)`
- 表头：#666 白字
- 表格：两列
  - 名称（左对齐）
  - 含量（mg/m³，`.mono`）
- 默认行：总烃、甲烷、非甲烷总烃
- 空值：显示 `-`

**视觉规范**：
- 单元格 padding 8x10
- 行分隔线 #eee

## 6) 状态与异常提示（最小集）
- 未选择设备：状态显示“未选择设备（自动）”，开始/停止禁用
- 后端禁用控制：按钮禁用；点击时提示“control disabled…”（或统一提示“控制未开启”）
- 设备在线但无曲线：调试行提示 `143=0` 或 last143 很久；页面不报错，仅保持空曲线
