# TCD气相色谱单因素对比实验记录表

## 一、系统配置说明

### 1.1 实际硬件配置

本系统采用保温箱整体控温设计，所有关键组件均在保温箱内：

| 组件 | 温控方式 | 说明 |
|------|----------|------|
| 保温箱 | Modbus温控模块CH2 | 整体环境温度控制，40-80℃可调 |
| 色谱柱 | 保温棉包裹 | 无独立加热，依赖箱温 |
| 进样口 | 保温棉包裹 | 无独立加热，依赖箱温 |
| 检测器(TCD) | 铜盒+保温棉 | 无独立加热，依赖箱温 |

### 1.2 可调节变量

| 变量类别 | 变量名称 | 可调范围 | 步进值 | 单位 |
|----------|----------|----------|--------|------|
| 温度 | 保温箱温度 | 40-80 | 5 | ℃ |
| 流量 | 载气流速 | 10, 20, 30 | 10 | mL/min |
| 流量 | 参考池流速 | 10, 20, 30 | 10 | mL/min |
| 电气 | 桥流 | 20-30 | 1 | mA |
| 环境 | 热风循环 | 开/关 | - | - |
| 环境 | 柱体保温 | 有/无保温棉 | - | - |

## 四、使用说明

### 4.1 实验执行流程

1. 确定实验方案和变量范围
2. 填写"实验基本信息"
3. 按变量类型选择对应记录表
4. 设定第一个变量值，等待系统稳定
5. 进行3次重复分析，记录完整数据
6. 改变下一个变量值，重复步骤4-5
7. 汇总数据到"实验汇总分析表"
8. 分析得出最优参数组合

### 4.2 稳定性要求

| 变量类型 | 稳定时间 | 测量次数 |
|----------|----------|----------|
| 温度改变 | 15-30分钟 | 3次取平均 |
| 流量改变 | 5-10分钟 | 2次取平均 |
| 桥流改变 | 5分钟 | 3次取平均 |
| 热风循环切换 | 30分钟 | 3次取平均 |
| 保温状态改变 | 15分钟 | 3次取平均 |

### 4.3 数据记录规范

- 温度：保留1位小数，单位℃
- 流量：保留2位小数，单位mL/min
- 桥流：整数，单位mA
- 峰面积：记录原始值
- 峰高：保留2位小数，单位mV
- 保留时间：保留3位小数，单位min
- 半峰宽：保留3位小数，单位min
- 拖尾因子：保留2位小数
- 信噪比：整数
