# 气相色谱 EPC (电子压力/流量控制器) Modbus RTU 协议规范

## 1. 协议背景与国际标准现状分析
根据对当前最新工业标准（如 Alicat, ABB, Brooks 等质量流量控制器与电子压力控制器）的调研：
1. **传输层标准**：国际上统一采用 **Modbus RTU (基于 RS-485)**，符合 `IEC 61158` 与 `GB/T 19582` 标准。
2. **应用层/寄存器映射**：国际上**没有统一的寄存器地址映射标准**，各主流厂商均基于其自身硬件特性定义私有寄存器。
3. **数据格式共识**：对于气相色谱要求的高精度（如 0.001 psi），业界普遍采用 **IEEE 754 标准的 32 位浮点数 (Float32)** 并在 Modbus 中占用 2 个连续的 16 位寄存器，字节序通常采用大端模式（Big-Endian, ABCD）。

基于上述事实，并结合**极简与高兼容性**的硬件对接要求，本规范对功能码进行了收敛，**全盘统一采用 `0x03` 和 `0x06` 功能码**进行读写。

---

## 2. 物理层与链路层配置 (默认参数)
- **物理接口**: RS-485 (两线制，半双工)
- **协议类型**: Modbus RTU
- **默认从机地址**: `21` (`0x15`)
- **默认波特率**: `9600` bps
- **数据位**: 8
- **校验位**: 无 (None)
- **停止位**: 1
- **字节序 (Endianness)**: 高字节在前，低字节在后 (Big-Endian / ABCD)

---

## 3. 支持的 Modbus 功能码
为了简化单片机固件的开发和上位机驱动的适配，本协议对功能码进行了精简：

| 功能码 (16进制) | 名称 | 作用说明 |
|---|---|---|
| `0x03` | Read Holding Registers | **读保持寄存器**。统一使用此功能码读取所有数据（将实时压力/流量等只读数据也映射至保持寄存器空间统一读取）。 |
| `0x06` | Write Single Register | **写单个寄存器**。用于下发 16 位整型控制指令（如切换模式、修改状态）。 |
| `0x10` | Write Multiple Registers | **写多个寄存器**。专门用于一次性下发 32 位浮点数设定值（如目标压力、目标流量），保证高低位数据写入的原子性。 |

---

## 4. 寄存器地址映射表 (Register Map)
> 所有寄存器均映射到 `4xxxx` (Holding Registers) 空间，以便统一使用 `0x03` 功能码进行单次批量读取。

### 4.1 实时数据区 (只读, 强制用 `0x03` 轮询)
> 建议色谱工作站以 200ms 周期集中读取该区域，以获取实时谱图曲线所需数据。若对此区域使用 `0x06`/`0x10` 写入，从机应忽略并返回异常码。

| 地址(10进制) | 地址(16进制) | 寄存器名称 | 数据类型 | 单位 / 说明 |
|---|---|---|---|---|
| 40001 | `0x0000` | 实时压力值 (高位) | Float32 | kPa / psi / bar (取决于单位配置) |
| 40002 | `0x0001` | 实时压力值 (低位) | | |
| 40003 | `0x0002` | 实时流量值 (高位) | Float32 | mL/min / sccm (由压力传感器与比例阀推算) |
| 40004 | `0x0003` | 实时流量值 (低位) | | |
| 40005 | `0x0004` | 比例阀实际开度 | UInt16 | `0 ~ 10000` (代表 0.00% ~ 100.00%) |
| 40006 | `0x0005` | EPC 硬件运行状态 | UInt16 | `0`: 正常<br>`1`: 传感器异常<br>`2`: 压力超限(报警)<br>`3`: 目标未达(调节中)<br>`4`: 阀门卡死 |
| 40007 | `0x0006` | 内部环境温度 | Int16 | `0.1 ℃` (例如 250 表示 25.0 ℃，用于温度补偿) |

### 4.2 控制与设定区 (读用 `0x03`, 写用 `0x06`/`0x10`)
> 用于工作站下发控制指令与目标设定值。

| 地址(10进制) | 地址(16进制) | 寄存器名称 | 数据类型 | 说明 |
|---|---|---|---|---|
| 40021 | `0x0014` | 控制模式 (Control Mode) | UInt16 | 使用 `0x06` 写入。<br>`0`: 待机 (比例阀全关)<br>`1`: 恒压控制模式<br>`2`: 恒流控制模式<br>`3`: 吹扫模式 (比例阀全开) |
| 40022 | `0x0015` | 目标压力设定值 (高位) | Float32 | 使用 `0x10` 功能码，向 0x0015 连续写入 2 个寄存器 |
| 40023 | `0x0016` | 目标压力设定值 (低位) | | |
| 40024 | `0x0017` | 目标流量设定值 (高位) | Float32 | 使用 `0x10` 功能码，向 0x0017 连续写入 2 个寄存器 |
| 40025 | `0x0018` | 目标流量设定值 (低位) | | |
| 40026 | `0x0019` | 载气类型 (Gas Type) | UInt16 | 使用 `0x06` 写入。<br>`0`: N2 (氮气)<br>`1`: He (氦气)<br>`2`: H2 (氢气)<br>`3`: Ar (氩气)<br>`4`: Air (空气) |
| 40027 | `0x001A` | 物理单位设定 (Units) | UInt16 | 使用 `0x06` 写入。<br>`0`: kPa & mL/min<br>`1`: psi & sccm<br>`2`: bar & L/min |

### 4.3 系统配置与标定区 (读用 `0x03`, 写用 `0x06`/`0x10`)
> 此区域用于设备初始标定与底层配置，日常运行不频繁调用。

| 地址(10进制) | 地址(16进制) | 寄存器名称 | 数据类型 | 说明 |
|---|---|---|---|---|
| 40050 | `0x0031` | Modbus 从机地址 | UInt16 | 使用 `0x06` 写入。<br>`1 ~ 247` (出厂默认 21)，修改后重启生效 |
| 40051 | `0x0032` | 串口波特率配置 | UInt16 | 使用 `0x06` 写入。<br>`0`: 4800, `1`: 9600(默认), `2`: 19200, `3`: 38400, `4`: 115200 |
| 40052 | `0x0033` | 压力-流量标定系数 K (高位) | Float32 | 使用 `0x10` 连续写入。<br>用于底层算法：Flow = K * Pressure |
| 40053 | `0x0034` | 压力-流量标定系数 K (低位) | | |

## 5. 解耦与独立自治逻辑 (工作站与固件对接核心规则)

**【架构铁律】：设备必须独立自治，工作站与设备绝对解耦。**
工作站仅作为“监视器”与“参数配置器”，绝对不参与 EPC 的内部工作流或启动时序。EPC 必须具备独立的工作能力与状态记忆能力。

1. **EPC 独立工作流 (固件端要求)**：
   - EPC 内部必须将“控制模式”、“目标压力”、“目标流量”、“载气类型”等设定值保存在非易失性存储器（如 EEPROM/Flash）中。
   - EPC 每次上电启动后，必须**自动读取断电前的参数并直接进入工作状态**（如直接恢复恒流模式并调节比例阀），无需等待工作站的任何初始化指令。
   - EPC 内部的 PID 闭环控制由单片机独立完成，无论通信线是否断开，EPC 必须维持当前设定的物理状态。

2. **工作站的异步配置 (UI与后端对接)**：
   - 当用户在 UI 界面上修改目标流量时，工作站后端使用 `0x10` (写浮点数) 和 `0x06` (写控制模式) 将参数异步下发给 EPC。
   - 写入完成后，工作站的配置任务即宣告结束，不负责监控执行过程的中间态，执行与达成目标完全是 EPC 自己的任务。

3. **工作站的集中轮询 (只读监视)**：
   - 工作站后端维持一个独立的定时器，使用一条 `0x03` 指令（起始地址 `0x0000`，读取数量 `7`）集中拉取 EPC 的实时状态。
   - 拿到的实时压力、流量、状态码仅供界面绘图和状态显示使用。

4. **安全保护与熔断 (设备端为主，工作站为辅)**：
   - **设备端防线 (绝对安全)**：EPC 底层固件必须具备硬件级熔断逻辑，如果传感器反馈压力超过物理极限，EPC 必须自主强制切断比例阀，将状态码 (`0x0005`) 置为异常，无需工作站干预。
   - **工作站防线**：当轮询读取到异常状态码时，工作站仅在 UI 弹出警报，并可下发 `0x0014` = `0` (待机) 作为辅助确认指令。
