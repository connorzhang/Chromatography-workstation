# 变更记录

## [v0.3.18] - 2026-05-29 (当前联调进度)
- **底层协议修正 (GCKC Legacy)**：
  - 彻底破解并修复遗留硬件控温开关逻辑：`Cmd 16` 确认为**状态翻转 (Toggle)** 指令，废弃原以为的 `Cmd 17`。
  - 修正 `Cmd 67` 控温通道使能位掩码映射，解决进样2 (Det2) 与检测2 (Inj2) 控制反转的问题。
  - 修复温度下发 `Cmd 8` 缺失保护温度导致硬件断电降温的致命 Bug。
  - 修正 BCD 温度编码算法，确保浮点数精确放大并正确拆分高低位。
- **Modbus 温控模块扩展**：
  - 新增 Modbus 独立温控模块的 **IO 输出模式** 支持。
  - 支持向寄存器 78 配置为 IO 模式的通道（如通道5~8，对应线圈地址 36~39）下发开关量指令。
  - 在前端调试 (Debug) 页面新增独立的 "开关量输出测试 (IO 模式)" 面板。
- **前端与全栈优化**：
  - 前端设置页新增硬件“获取中/升温中 (ON)/已停止 (OFF)” 实时状态指示灯。
  - 解决后端重启后 API 状态丢失导致 404 的问题，前端强制透传 `deviceId`。
  - 同步更新相关协议文档 (`GCKC_PROTOCOL_DEVELOPER_GUIDE.md`, `GCKC_PROTOCOL_COMMAND_REFERENCE.md`, `温控模块Modbus通信协议说明.md`)。

## 2026-05-11

- 修复 `IBrainChrom.csproj` 文件开头重复 BOM 导致的加载失败（“根级别上的数据无效”）。
